# Supplementary material and reproduction package — v5.0.0

This repository contains the complete supplementary material and computational reproduction package for:

> Yashar Amani and Masoud Masih-Tehrani, “Falsification-First Evaluation of Inertial Sensor Reference, Sampling, and Excitation for Vehicle Roll Identification.”

All signals and experiments are synthetic. The package supports inspection, reproduction, and reuse of the reported sensor-design study under the MIT License.

[![DOI](https://zenodo.org/badge/1399922425.svg)](https://doi.org/10.5281/zenodo.24389777)

## Repository contents

- `supplementary_material.tex` and `supplementary_material.pdf`: standalone supplementary document.
- `analysis/analysis_config.json`: frozen physical, sensor, and experiment configuration.
- `analysis/generate_and_analyze.py`: analytical generator, estimators, controlled comparisons, diagnostics, tables, traces, and figures.
- `results/all_fits.csv`: 810 distinct full-parameter fits.
- `results/inertia_profiles.csv`: 12,060 fixed-inertia profile reoptimizations.
- `results/`: complete estimator, sampling, placement, excitation, payload, road, profile, and metadata tables.
- `data/selected_trace_seed001_100Hz.csv`: antialiased 100-Hz trace produced through the analyzed signal path.
- `figures/`: raster and vector figures generated by the analysis.
- `requirements.txt`: pinned Python package versions.
- `checksums.sha256`: SHA-256 inventory of release files.
- `validate_supplement.py`: numerical, provenance, trace, checksum, and LaTeX validation.

## Reproduction

From the repository root, run:

    make all

The individual targets are:

    make reproduce
    make compile
    make checksums
    make validate

A successful run ends with:

    OK: supplementary package v5.0.0 validated; 810 fits, 12060 profile reoptimizations

## Evidence boundary

The generator is a transparent linear two-state roll model rather than a validated vehicle digital twin. The principal input is a noisy geometry-compensated roll-axis acceleration channel, not an uncorrupted truth signal or raw phone-frame measurement. Sampling cases are retained output rates obtained by offline noncausal filtering of a 200-Hz record. Road proxies are synthetic deterministic regressors. Payload cases are simulation acquisition-pairing scenarios, not field-repeat uncertainty.
